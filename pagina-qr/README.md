# Página do QR code (versão com API)

Cópia de referência da página publicada no repositório [chamar-ti](https://github.com/gabrielgermanoraphael-del/chamar-ti) (GitHub Pages).

- Login com o Google institucional, código de liberação e acesso por sala.
- Tela **"O TI resolveu?"**: o professor confirma ou recusa (com motivo) os chamados que o técnico marcou como resolvidos.

Para publicar: preencha `API_URL` com o endereço da API e copie este `index.html` para o repositório `chamar-ti`. Os QR codes impressos continuam os mesmos.
